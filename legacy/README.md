# Japandetali.ru Legacy System

## Назначение сайта

Japandetali.ru — сайт продажи и подбора автомобильных запчастей. Текущая версия представляет собой legacy-систему на Bitrix с пользовательским интерфейсом каталога, поиском деталей, корзиной и личным кабинетом.

## Основные функции сайта

### Информационные разделы

- О нас — информация об организации.
- Оплата — раздел существует, носит только информационный характер.
- Доставка — информационный раздел.
- Возврат — информационный раздел.
- Контакты — контактная информация организации.
- Акции — раздел существует, активные предложения не обнаружены.

## Поиск запчастей

### Поиск по VIN номеру

На сайте присутствует раздел поиска по VIN номеру.

Текущее состояние:

- интерфейс доступен пользователю;
- функциональность не работает или требует дополнительного исследования. В данный момент при попытке поиска "Доступ заблокирован. Срок действия лицензии закончился"

### Поиск по номеру запчасти

В интерфейсе присутствует строка поиска по номеру запчасти. Фактически поиск производится также по названию детали.

Назначение:

- поиск деталей по идентификатору/номеру запчасти.

Реальная логика поиска требует проверки в коде Bitrix.

## Личный кабинет

Доступен через регистрацию и выход пользователя.

Функции:

- просмотр текущих заказов;
- изменение личных данных.

Поля профиля:

- Имя;
- Фамилия;
- Отчество;
- Email;
- Новый пароль;
- Подтверждение пароля.

Особенности:

- обязательным является только Email;
- доступны действия сохранить и сбросить.

## Корзина

На самой кнопке "В корзине" отображается количество товаров в корзине например (В корзине: 1)

Основное поле Корзины.

Корзина может быть пуста или наполнена товарами.

Если есть хотя бы один товар, то отображается таблица с полями:
- Наименование
- Цена
- Кол-во(шт)
- Сумма

Ниже таблицы Итоговая сумма и кнопка оформления заказа.

Детальная логика оформления заказа требует исследования.

## Общая структура страницы

Верхняя часть:

- информационное меню;
- регистрация/личный кабинет;
- поиск запчастей;
- корзина.

Основная область:

- каталог/контент сайта.

Нижняя часть:

- повторная контактная информация организации.

## Неисследованные области

Требуют проверки через код и сервер:

- каталог товаров;
- наличие запчастей;
- цены;
- интеграция с 1С;
- структура заказов;
- платежные системы;
- службы доставки;
- API;
- база данных.
