# Документация нового проекта

Эта папка описывает целевой сайт автозапчастей на Go, React и PostgreSQL. Первый этап — современный сайт-визитка с обращением к менеджерам; магазин и интеграции развиваются после него. Исследовательские материалы о предыдущем сайте хранятся отдельно в [`legacy/`](../legacy/).

## Документы

1. [Требования к продукту](01-product-requirements.md) — назначение сайта и ключевые возможности первого этапа.
2. [Первый релиз](02-mvp-scope.md) — состав сайта-визитки и последующие этапы развития магазина.
3. [Пользовательские сценарии](03-user-flows.md) — пути посетителя и менеджера.
4. [Доменная модель](04-domain-model.md) — модель для следующего этапа: каталог, предложения и заказы.
5. [Расширенная схема развития](05-future-system-flow.md) — путь от работающего сайта-визитки к магазину с поставщиками и 1С.
6. [Структура и контент сайта](06-site-structure-and-content.md) — страницы, секции и черновые тексты первого релиза.
7. [Дизайн-направление](07-design-direction.md) — визуальный характер бренда, палитра, типографика и правила интерфейса.

## Принципы новой системы

- Посетитель сразу понимает, какие запчасти и услуги предлагает компания.
- Основной призыв к действию — написать менеджеру в удобный мессенджер.
- Контакты и ссылки на мессенджеры доступны в шапке, ключевых секциях и подвале.
- Будущие функции магазина не усложняют первый релиз.

Frontend первого этапа находится в [`../frontend/`](../frontend/), инструкция по запуску — в [`../frontend/README.md`](../frontend/README.md). Правила ценообразования, интеграции, схема PostgreSQL и API потребуются позднее, на этапе магазина. Будущий backend на Go будет размещён в отдельной папке `backend/` в корне проекта.
